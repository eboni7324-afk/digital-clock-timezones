# Security Policy

## Reporting a vulnerability

If you discover a security issue in this project, please report it privately and responsibly.

Please email:

- Ebony Butler: eboni7324@gmail.com

Include:
- a description of the issue
- affected files or functions
- reproduction steps if applicable
- any suggested fix or mitigation

## Response expectations

We will review vulnerability reports as quickly as practical and coordinate a remediation where appropriate.

## Disclosure policy

Please do not publicly disclose vulnerabilities until a fix has been prepared and communicated.

## Scope

This policy applies to the project code, configuration, and project assets published in this repository.
