# World Clock

A simple digital clock app that shows the current time in multiple time zones.

**Built by Ebony Butler**

## Features
- Live local time display
- Multiple global time zones (New York, London, Paris, Tokyo, Sydney, Los Angeles, Dubai, Johannesburg)
- Responsive, modern design with glassmorphism UI
- Auto-updating every second
- Error handling for timezone formatting

## Run locally

Open `index.html` in a browser, or serve the project with a local static server.

Example using Python:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Project Files

- `index.html` – Page structure with semantic HTML
- `style.css` – Modern styling with gradients and animations
- `script.js` – Timezone logic and live clock updates
- `README.md` – Documentation

## Technologies

- HTML5
- CSS3 (Flexbox, Grid, Gradients, Animations)
- Vanilla JavaScript (Intl API for timezone formatting)
