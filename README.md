- Live local time display
- Multi-city world clock
- Responsive design
- Timezone formatting via the browser Intl API

## Local run instructions

Open `index.html` directly in a browser, or run:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```
